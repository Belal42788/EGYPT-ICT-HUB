## Working mechanisms

- Installation/peripherals: trusted-source and compatibility gates; three fictional package routes; extraction before ZIP setup; animated installation; invented storage use and uninstalling while retaining a student document; USB Plug and Play versus a legacy parallel printer, matching driver/port checks and a moving test sheet. No real download, installation, device changes or printing.
- Email: split a reserved example.com address; fixed account-walkthrough cards with parent/terms-review gates; fictional sign-in/out; separately saved inner-mailbox language; animated symbolic delivery into a dummy inbox. No real names, birth dates, passwords, phone numbers, codes, account creation or email sending.
- Big Data/AI: five processing stages and a real small numerical fit, not hardcoded predictions called learning. Least-squares linear regression is compared with cubic interpolation fitted only on four synthetic training points. Two held-out references show the flexible fit’s overfitting in this deliberately constructed example. Correcting a known synthetic measurement changes both fits. This is not big-data infrastructure, a general AI service or a universal verdict about model complexity.
- UX/UI: edit a contained fictional library’s navigation, clarity, consistency, layout and colours. The book-finding task really works. The automated journey takes four model clicks through the weak path or two through direct navigation. Ordinary-text contrast is computed from sRGB luminance and compared using the unrounded 4.5:1 threshold. Neither a contrast pass nor the toy click count is a full accessibility, satisfaction or speed assessment.
- Functions: animated caller/local-frame/console paths; parameter binding, return, print-only None, local scope, missing required arguments, circle area, maximum, fixed greeting and two multiplication calls totalling 26. Displayed code is correctly indented. Programs are fixed models, not an arbitrary Python runtime.
- Input errors: separate parsing and division failures, typed handlers, normal paths, two-input evaluation order, negative-age semantic validation, retrying until an integer and accepting zero. The trace follows execution and automatically shows the latest output. Unsupported input syntax/ranges are labelled interface limits, not fabricated Python errors.

## Source corrections and boundaries

Read all twelve complete Arabic/English lesson extracts, including exercises, and inspected four relevant source-page images. Source ranges use physical PDF page numbers, not printed chapter labels.

- Installation screenshots use historical Windows 7 examples, not universal current-system instructions. Uninstalling is not claimed to delete every file or always speed the machine.
- Email-provider age/supervision rules vary. No country-specific threshold or live account/signup claim is made. The address local part is unique within its domain, not necessarily globally.
- The textbook’s Arabic Overfitting label, **التجهيز الزائد**, is retained alongside explanation. We qualify broad claims that all AI needs big data, that more data guarantees accuracy, or that improvement happens simply with time. Rule-based systems exist.
- UX and UI overlap. Red or yellow is not inherently bad, and typography/contrast/context matter.
- A print-only function can be assigned without a syntax error, but its implicit result is None. Explicit return is not mandatory for every function. The first executed return exits its call.
- The English retry example on physical PDF page 57 genuinely omits try. It is restored with correct indentation and quotes. Typed expected exceptions are preferred to a bare except. try does not repair a pre-execution syntax error in the same file.
- Prep 3 input-error coverage ends at physical PDF page 63 in both books. Page 64 is the next unit’s cover and is excluded from this lesson’s source range.
- Prep 1’s supplied English and Arabic covers show different years. These lessons were compared directly across the supplied texts; the entire books are not assumed identical.

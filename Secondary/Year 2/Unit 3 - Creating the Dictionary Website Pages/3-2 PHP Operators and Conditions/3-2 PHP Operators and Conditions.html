هدفك في الدرس

تفرق بين الإسناد والمقارنة، وتستخدم المعاملات الحسابية والمنطقية، وتفسر if وelseif وswitch.

01 · حساب وتحديث القيم

العمليات الحسابية

+ للجمع، - للطرح، * للضرب، / للقسمة، و% لباقي القسمة الصحيحة. مثال 10 % 3 يساوي 1 لأن 10 = 3 × 3 + 1. الباقي مش ناتج القسمة العشري. استخدم الأقواس لتوضيح ترتيب الحساب.

تحديث مختصر

$x += 5 تعادل $x = $x + 5، وبالمثل -= و*= و/= و%=. الزيادة ++ تغير القيمة بواحد، والنقصان -- ينقصها واحدًا. لا تخلط تحديث المتغير بنتيجة اختبار مقارنة.

02 · مقارنة ومنطق

= مش ==

= يخصص قيمة. == يختبر التساوي، و!= عدم التساوي، و> و< و>= و<= للمقارنة. الشرط ينتج True أو False. أمثلة الدرس تستخدم أعدادًا صحيحة لتجنب خلط تحويل أنواع البيانات بالمقارنة.

AND وOR وNOT

&& تعني تحقق الشرطين معًا. || تعني تحقق واحد على الأقل، وتشمل تحقق الاثنين. ! تعكس القيمة المنطقية. مثلًا إذا x = 5 فشرط x > 0 && x < 10 صحيح؛ إذا x = 12 فهو خطأ.

03 · اختيار المسار

if وelse وelseif

if تنفذ الكتلة عند صحة الشرط. else بديل عند عدم تحققه. سلسلة elseif تختبر الشروط بالترتيب وتتوقف عند أول فرع متحقق. مثال التصنيف:سالب إذا x < 0، ثم موجب إذا x > 0، وإلا صفر.

التعبير الثلاثي

الصيغة (condition) ? valueIfTrue:valueIfFalse تختار قيمة حسب شرط. مثل $label = ($x == 1) ? "One" : "Other";. هي تعبير يرجع قيمة، وليست قاعدة عامة لكتابة أي عدد من التعليمات في سطر واحد.

04 · switch واختبار الحدود

case وbreak وdefault

switch تختار حسب قيمة:case 1 ثم case 2 وهكذا. break تخرج من switch وتمنع الاستمرار للفرع التالي. يمكن تجميع أكثر من case لنفس الكود. default تعالج عدم التطابق. exit تنهي السكربت كله، وليست مرادفًا لـ break.

اختبر الحد نفسه

لشرط x > 0 اختبر -1 و0 و1، مش قيمة موجبة واحدة فقط. جرّب المعمل بقيم سالبة وصفر و1 و10، وقارن الفرع وناتج الشرط وباقي القسمة. كل النتائج هنا محسوبة في المتصفح كمحاكاة، لا بتنفيذ PHP.

$x = 5;
if ($x < 0) {
  echo "Negative";
} elseif ($x > 0) {
  echo "Positive";
} else {
  echo "Zero";
}

اختبار نهاية الدرس

كل سؤال له إجابة واحدة. بعد الاختيار تظهر الإجابة والتفسير. التخطي يكشف الحل بدون نقطة.

الخلاصة

احسب أولًا، ثم اختبر شرطًا ينتج قيمة منطقية. = للإسناد و== للمقارنة. if تختار مسارًا، وswitch تنظم حالات القيمة. اختبر الحدود وتأكد من break.

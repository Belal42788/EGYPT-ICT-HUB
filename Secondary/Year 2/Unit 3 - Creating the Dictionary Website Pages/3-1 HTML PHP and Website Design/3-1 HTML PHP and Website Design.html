هدفك في الدرس

تشرح هيكل HTML والروابط وواجهة Expression Web، وتتتبع متغيرات PHP واستدعاء الملفات والاتصال.

01 · ملفات المشروع

Dictionary داخل htdocs

ينظم الكتاب المشروع في مجلد Dictionary داخل htdocs في بيئة XAMPP، مع مجلدات فرعية للصور والوسائط. مسار القرص يحدد مكان الملف على الجهاز، أما عنوان localhost فيطلب الصفحة من خادم محلي. تأكد من المسار الفعلي عند المعلم بدل نسخ أي خطأ مطبعي.

صفحات ووظائف مشتركة

الصفحات هي Index وAdd_Term وSearch_Term وEdit_Term وDel_Term وHelp بامتداد php. Header.php يجمع صورة الرأس والروابط، وConnection.php يجمع الاتصال. صلاحية التعديل والحذف موضوع أمان لاحق في المصدر، وليست مفعّلة في هذه المحاكاة.

02 · هيكل HTML

head وtitle وbody

HTML لغة ترميز. html يضم المستند، وhead معلوماته، وtitle عنوان تبويب المتصفح، وbody المحتوى الظاهر. الوسم غالبًا له بداية ونهاية، مثل p وh1. br فاصل سطر لا يحتاج وسم إغلاق. احفظ الملف كنص بامتداد html، لا ملف معالجة نصوص بتنسيق خاص.

صورة ورابط وقسم

img يستخدم src لمسار الصورة، وa يستخدم href لوجهة الرابط، وdiv يجمع جزءًا من الصفحة. كتابة كلمة «بحث» وحدها لا تحولها إلى رابط. h1 إلى h6 مستويات عناوين، وليست بديلًا عن تنسيق النص وفق معنى المحتوى.

03 · Expression Web والرأس المشترك

تصميم مرئي وكود

واجهة Expression Web في الكتاب تتضمن شريط القوائم، قائمة المجلدات، خصائص الوسم، منطقة مكونات الموقع، صندوق الأدوات، وتطبيق الأنماط. WYSIWYG تعني «ما تراه هو ما تحصل عليه»؛ تقدر تراجع كود HTML الناتج وتعدله بدل الاعتماد على الشكل وحده.

الرأس: Banner ثم روابط

Header.php يحتوي صورة رأس وروابط الوظائف. المصدر يستخدم div وimg وروابط a ومسافات &nbsp;. استدعاء الملف من الصفحات يقلل النسخ. المعاينة أدناه تعلم فكرة HTML فقط، وليست نسخة من برنامج Expression Web.

04 · أساسيات PHP

متغيرات وطباعة وتعليقات

المتغير يبدأ بـ $ مثل $term، ولا يبدأ اسمه برقم، وأسماء المتغيرات حساسة لحالة الحروف. = للإسناد، و; تنهي التعليمة. echo وprint للإخراج، والنقطة . لربط النصوص. داخل نص مزدوج الاقتباس يمكن إدراج قيمة المتغير؛ الاقتباس المفرد يعرض اسمه كنص. التعليقات // أو /* ... */ لا تنفذ.

أنواع وثوابت

الكتاب يعرض String وInteger وDouble وBoolean، وgettype لمعرفة النوع. الثابت يعرّف مثل define("SITE_NAME", "Dictionary"); ويستخدم بدون $. توضيح تصحيحي: PHP هو الذي ينفذ الكود، وليس Apache مترجمًا له. الثوابت في PHP الحالي حساسة للحروف؛ لا تتبع صيغة تجاهل الحروف القديمة في الكتاب.

05 · الاتصال وقراءة الكود القديم

أربع معلومات للاتصال

تحتاج عملية الاتصال إلى الخادم واسم المستخدم وكلمة المرور واسم قاعدة البيانات. بعد الاتصال تختار القاعدة وتفحص الفشل قبل الاستعلام. هنا نختار نتائج وهمية فقط، ولا نطلب منك كلمة مرور ولا نعرض بيانات اتصال حقيقية.

تنبيه عملي عن mysql_*

المصدر يعرض mysql_connect وmysql_select_db. هذه واجهة قديمة أزيلت من PHP 7؛ ليست كودًا جاهزًا للتشغيل على PHP الحالي. لفهم المنهج اقرأ الهدف والتدفق، ولتنفيذ حديث استخدم MySQLi أو PDO مع إعدادات آمنة وبإشراف المعلم. مراجع التصحيح موضحة في نهاية الدرس.

الخلاصة

HTML يبني الهيكل والروابط. Expression Web أداة تصميم في الكتاب. PHP ينفذ على الخادم ويتعامل مع المتغيرات والملفات والاتصال. افهم الكود القديم، ولا تعتبره تنفيذًا حديثًا جاهزًا.

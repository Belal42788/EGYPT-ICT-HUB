هدفك في الدرس

تميّز أنواع البرامج والصفحات، وتفسّر دور المتصفح والخادم وقاعدة البيانات، وتختار أدوات المشروع.

01 · البرامج والصفحات

مجاني مش معناه مفتوح المصدر

البرامج المجانية (Freeware) متاحة للاستخدام دون مقابل وفق ترخيص صاحبها. البرامج مفتوحة المصدر تتيح الاطلاع على الكود وتعديله وإعادة توزيعه وفق ترخيصها. السعر وحده مش هو الفرق.

صفحة ساكنة وصفحة ديناميكية

الصفحة الساكنة تعرض محتوى محفوظًا، مثل صفحة تعريف مكتوبة بـ HTML. المثال الديناميكي في الكتاب يعالج طلبًا على الخادم، مثل البحث عن مصطلح في قاعدة بيانات. وجود حركة في الصفحة وحده لا يثبت أن الخادم يعالج بيانات.

02 · مين بيعمل إيه؟

الخادم والمتصفح

المتصفح يعرض الصفحة للمستخدم. الخادم (Server) قد يعني جهازًا يقدّم خدمة، أو برنامجًا يؤدي دور الخدمة. الأمثلة: خادم ويب للصفحات، وخادم طباعة للمهام، وخادم بريد للرسائل. الدور هو المهم، مش إن الجهاز لازم يكون الأكبر دائمًا.

تعليمات عند العميل أو الخادم

الـ Script مجموعة تعليمات تنفّذ مهمة. JavaScript يمكنه العمل داخل المتصفح، مثل فحص خانة فارغة. PHP يعمل على الخادم لمعالجة الطلبات. فحص المتصفح يساعد المستخدم، لكنه لا يغني عن فحص الخادم.

HTML وPHP

HTML لغة ترميز لبناء هيكل الصفحة، مش لغة لتنفيذ استعلام قاعدة بيانات. PHP لغة برمجة من جهة الخادم، ويمكن دمج كودها مع HTML. امتداد الملف قرينة أحيانًا، لكنه مش اختبارًا مضمونًا لنوع الموقع.

03 · تخزين البيانات وأدوات التشغيل

SQL وMySQL

SQL لغة للتعامل مع البيانات: INSERT للإضافة، SELECT للاستعلام، UPDATE للتعديل، DELETE للحذف. MySQL نظام لإدارة قواعد البيانات العلائقية؛ يعني البرنامج الذي يدير الجداول، مش اسم اللغة نفسها.

Apache وحزم خادم الويب

Apache برنامج خادم ويب. ضمن بيئة مجهزة يمكنه توجيه طلبات PHP للمعالجة. الكتاب يعرّف حزم LAMP للينكس، WAMP لويندوز، MAMP لماك، وXAMPP متعددة المنصات، لتجميع أدوات الخادم وقاعدة البيانات وPHP. أسماء الأدوات هنا حسب الكتاب، وليست تعليمات لتثبيت إصدار بعينه.

اختبار محلي ونشر على الإنترنت

Localhost يعني إنك تختبر الخدمة على جهازك. النشر على استضافة يتيح الزيارة عبر عنوان الموقع حسب إعدادات الوصول. الجلسة (Session) تحتفظ بحالة الزيارة بين الطلبات، مثل هوية مستخدم مسجّل. في أمثلتنا نستخدم بيانات وهمية ولا نخزّن كلمات مرور.

اختبار نهاية الدرس

كل سؤال له إجابة واحدة. بعد الاختيار تظهر الإجابة والتفسير. التخطي يكشف الحل بدون نقطة.

الخلاصة

السعر لا يحدد إتاحة الكود. المتصفح يعرض، والخادم يعالج طلبات المشروع. HTML يبني الهيكل، PHP يعالج، SQL يستعلم، وMySQL يدير البيانات. اختبر محليًا قبل النشر.

الكتاب: الوحدة الأولى، الموضوع الأول. النسخة الإنجليزية ص 9–19، والعربية ص 7–16.

صياغة تعليمية مبسطة من الكتاب، وليست نقلًا حرفيًا. فحص المتصفح لا يغني عن فحص الخادم. لا تستخدم كلمات مرور أو بيانات شخصية في التدريب.

# Year 2, Unit 1 pilot

Two bilingual standalone lessons for the supplied first-term textbook. These pages are a review batch and are not yet listed in secondary.html. They link to one another and to the existing home/stage pages. No Year 1 page or main index is changed by this batch.

## Sources

- Information and Communication Technology, Second Year Secondary, First Term, 2026-2027, The Web Site Design Project, English edition: topic 1 printed pp. 9-19; topic 2 printed pp. 20-28. The project homepage is Figure 4 on printed p.22.
- Corresponding Arabic edition: topic 1 printed pp.7-16; topic 2 printed pp.17-25.

The original PDFs were checked, including the homepage figure. Page ranges refer to printed book pages, not PDF leaf indices. Installation and startup activities refer to an activities/exercises book in the source; this pilot does not claim to reproduce that separate book's procedures.

## Coverage

1-1: freeware/open-source licences; static/dynamic pages; server hardware/software roles; scripts and browser/server execution; HTML/PHP; Apache; local testing/hosting; SQL operations; MySQL; LAMP/WAMP/MAMP/XAMPP; session state. A stepped browser/server/database/response demonstration supports two matching tasks and six explained end questions.

1-2: dictionary project purpose; term fields; add/search/edit/delete/help features; homepage functions; project folder organization; local testing and tools; database/static-page/dynamic-integration stages; test cases. A stepped project demonstration and six-button feature map support two tasks and six explained end questions.

## Teaching clarifications

The prose is adapted and simplified, not a verbatim reproduction. Jargon is defined near its first use. File extensions are described as clues, not proof of how a site works. A server is described by its service role rather than a requirement to be the largest machine. Browser validation does not replace server validation. The session example avoids teaching password storage. Tool names follow the textbook without prescribing an unverified current download or version.

The dictionary feature map is an original teaching layout based on the textbook's functions, not a copied software screenshot. All examples use dummy information. No passwords, real personal data, live database, native program, installation or server-side execution is involved.

## Interaction contract

- Demos: previous, next, play/pause and replay. State changes update a highlighted process node, progress bar, explanation and counter.
- Tasks: all three selections required before checking; per-row feedback; retry/reset. Wrong answers do not count as correct selections.
- Quiz: six single-answer questions per page; right/wrong explanation; skip reveals without a point; restart clears answers; score separates answered, correct and skipped.
- AR/EN toggle changes page direction and all dynamic feedback while preserving selections, quiz answers, current demo step and feature-map selection.
- Practice/quiz activity is in memory only, not saved after reload. Only language preference uses localStorage.
- Responsive layout at 360/390px and desktop, touch-friendly controls, native select labels, keyboard-operable buttons, visible focus styles and reduced-motion CSS.

إنتاج محاكاة OR باستخدام VB.NET

اربط عناصر الواجهة بالحالة، وحدّث المخرج بعد كل نقرة.

هدفك في الدرس

تحدد عناصر المشروع، وتتتبع أحداث التحميل والنقر، وتختبر كل حالات OR.

ملاحظة ترجمة: النسخة المرفقة من الوحدة الثانية إنجليزية فقط؛ النص العربي ترجمة تعليمية مسودة للمراجعة.

01 · هدف المشروع وواجهته

من قاعدة إلى برنامج

ننتج محاكاة لسلوك OR، وليس تحكمًا في مصباح حقيقي. المخرج 1 إذا كان مدخل واحد على الأقل 1، ويشمل ذلك أن يكون الاثنان 1. نحدد المدخلات والمخرج قبل اختيار أدوات الواجهة.

عناصر نسخة الكتاب

Form1، Button1 وButton2، وPictureBox1 للمصباح وPictureBox2 لصورة النموذج.

02 · تهيئة الحالة

البداية لازم تطابق القاعدة

في Form1_Load يبدأ المدخلان Off والمصباح Off. تُحمّل صور النموذج والمصباح من ملفات المشروع. تأكد من الأسماء والمسارات بدل الاعتماد على ترتيب الملفات.

حالة أم عنوان؟

الكتاب يمثل On وOff بنص ظاهر. اربط النص بالقيمة المنطقية بثبات، ولا تستخدم تغيير اللون دليلًا وحيدًا على الحالة. المعمل هنا يظهر A وB وY رقميًا ويوضح النتيجة بجانب المصباح.

03 · الحدث ومسار الكود

عند النقر

عند Button1.Click نعكس حالة المدخل الأول، ثم نعيد تقييم المخرج. عند Button2.Click نطبق الفكرة نفسها على المدخل الثاني؛ لازم يحدث تحديث المخرج من الحدثين.

الفرع الذي يكشف الخطأ

إطفاء مدخل واحد لا يطفئ المصباح إذا ظل الآخر 1. الخطأ الشائع هو نسخ كود AND دون تغيير هذا الفرع. لهذا اختبر تغيرات متتالية، مش حالات منفصلة فقط.

04 · الصور والاختبار

ملف الصورة مش هو المنطق

on.jpg وoff.jpg صورتان بديلتان لنفس موضع العرض. الكود يختار الصورة حسب شرط البوابة. لو غابت صورة، افحص المسار، لكن لو المخرج غلط افحص الشرط والحالة أولًا. الرسم في معملنا أصلي للشرح، وليس لقطة من البرنامج.

اختبارات تكشف نسيان التحديث

اختبر 00→10→11→01→00، ثم ارجع بالعكس. الحالتان 10 و01 لازم تكونا 1، حتى عند إطفاء المدخل الآخر. المحاكاة هنا JavaScript في المتصفح فقط؛ تنفيذ VB.NET الفعلي يحتاج بيئته.

معمل التجربة

اقرأ الكود وتتبع الفكرة

مثال تعليمي مصاغ للشرح، وليس نقلًا حرفيًا لكل أسطر الكتاب. لا يتم تنفيذه هنا.

' Parameter lists (...) are abbreviated for reading, not compilation.
' Teaching excerpt: event parameter lists abbreviated.
Private Sub Form1_Load(...) Handles Me.Load
  Button1.Text = "Off"
  Button2.Text = "Off"
  PictureBox1.Image = Image.FromFile("off.jpg")
End Sub

Private Sub Button1_Click(...) Handles Button1.Click
  If Button1.Text = "Off" Then
    Button1.Text = "On"
    PictureBox1.Image = Image.FromFile("on.jpg")
  Else
    Button1.Text = "Off"
    If Button2.Text = "Off" Then
      PictureBox1.Image = Image.FromFile("off.jpg")
    End If
  End If
End Sub

Private Sub Button2_Click(...) Handles Button2.Click
  If Button2.Text = "Off" Then
    Button2.Text = "On"
    PictureBox1.Image = Image.FromFile("on.jpg")
  Else
    Button2.Text = "Off"
    If Button1.Text = "Off" Then
      PictureBox1.Image = Image.FromFile("off.jpg")
    End If
  End If
End Sub

الخلاصة

الواجهة تستقبل الحالة، والكود يطبق OR، ثم يحدّث العرض. افحص البداية وكل الحالات ومسارات الصور، ولا تعتبر المحاكاة تنفيذًا فعليًا للغة VB.NET.

What is Information Security?

Core Definition

Information security is the act of properly managing information and keeping it safe.

Protecting your data from unauthorized access

✅ Correct — that's information security

Publishing all your data publicly online

That exposes your data to risk — the opposite of information security

❌ Wrong — that's a risk to your data

The Three Essential Elements of Information Security

Confidentiality, Integrity, Availability

### The Information Security Triangle

Information security relies on 3 essential elements — click each one:

Confidentiality

A state in which only authorized individuals can access the information.

💡 If information leaks to unauthorized people = confidentiality is compromised.

Integrity

A state in which the information is not destroyed, tampered with, or erased.

💡 If data is altered by mistake = integrity is compromised.

Availability

A state in which information can be accessed at any time when needed.

💡 If a website goes down from an attack = availability is compromised.

### ⚠️ Common Mistakes

Confusing confidentiality and integrity — confidentiality prevents unauthorized viewing, integrity prevents tampering or destruction.

Forgetting availability — information you can't access when needed has lost availability even without a leak.

Various Threats to Information Security

Malware and Crimes

### Unauthorized Access and Cracking

Many threats can harm information security — click each one:

Unauthorized access

When someone without permission gains access to a computer system.

💡 Like someone using another person's user ID and password to enter a system.

Cracking

The act of unlawfully accessing a system to tamper with, erase, or steal data. A person who commits such acts is called a cracker.

💡 Difference from unauthorized access: cracking usually intends to steal or destroy.

### Malware

Malware is a general term for malicious programs designed to harm computers. Infection can occur through websites, email attachments, USB drives, or networks — click each type:

Computer virus

A program designed to intentionally cause harm, such as destroying data or programs.

💡 Needs a user action to spread (like opening an attachment).

Trojan horse

A program disguised as a legitimate one that infiltrates a system and quietly initiates attacks.

💡 Disguises itself as a useful program, but contains malicious code.

Worm

A program that replicates itself and spreads across the internet like a worm, expanding the infection.

💡 Spreads by itself without needing a user action.

Spyware

A program that collects personal information without the user's knowledge and sends it to third parties.

💡 Types: Keylogger (monitors keystrokes) and Adware (displays unwanted ads).

Ransomware

A program that renders data inaccessible and demands a ransom to restore access.

💡 Encrypts your data and asks you to pay to get it back.

### Cybercrime

Cybercrime is criminal acts committed over computer networks — click each type:

### 1. Violation of the Unauthorized Computer Access Law

Illegally accessing a computer using someone else's user ID or password.

### 2. Crimes involving computer or electronic records

Crimes involving tampering with stored data or unauthorized manipulation of devices.

### 3. Network-based crimes

Crimes committed using networks, such as fraud, defamation, or copyright infringement.

### ⚠️ Common Mistakes

Confusing a computer virus and a worm — a virus needs user action, a worm spreads by itself.

Thinking if the computer is offline there's no risk — no, USB drives and transferred files are infection sources too.

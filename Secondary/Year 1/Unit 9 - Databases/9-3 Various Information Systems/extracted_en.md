Lesson introduction — the various information systems

Information systems are everywhere around us — in stores and supermarkets, in transportation and roads, and in companies. Today we learn the four types: the Transaction Processing System TPS, Management Information System MIS, Decision Support System DSS, and Executive Information System EIS, then system integration vertical and horizontal, and the Enterprise Resource Planning system ERP.

Think of it this way:

Each system has its own job: TPS records daily transactions, MIS provides reports to managers, DSS supports difficult decisions, and EIS delivers summarized information to executives.

### ⚠️ Common Mistakes

Confusing MIS with DSS — MIS provides periodic reports to assist in decision-making, while DSS supports non-routine decisions through modeling and simulations.

Confusing vertical with horizontal integration — vertical links different levels (like TPS with MIS), while horizontal links systems at the same level across departments (like sales with inventory).

System Integration

vertical and horizontal — book page 119

System integration is linking different information systems together so they can exchange data and work together in an integrated way.

Integration is of two types: vertical, which links different levels of the organization, and horizontal, which links systems at the same level across departments.

Think of it this way:

Vertical is like linking the daily attendance log (TPS) with monthly manager reports (MIS) — different levels. Horizontal is like linking the sales system with the inventory system — the same level in two different departments.

the two types of integration

vertical — linking different levels

horizontal — linking the same level across departments

the result — a unified data flow

Enterprise Resource Planning

combining business functions into a single system — book page 119

The Enterprise Resource Planning system ERP is an integrated system that combines various business functions — such as accounting, human resources, supply chain, and customer relationship management CRM — into a single system.

Instead of each department having its own separate system, everything is in one unified system that easily exchanges data.

Think of it this way:

A company with ERP: when a product is sold, accounting, inventory, and supply chain all update at the same moment from one system.

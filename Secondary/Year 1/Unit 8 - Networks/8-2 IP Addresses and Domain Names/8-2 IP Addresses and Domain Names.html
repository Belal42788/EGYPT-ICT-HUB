الـ IP address (IP Address)

عنوان فريد لكل جهاز — بالكتاب

الـ IP address هو رقم تعريف فريد زي العنوان بالظبط، بيتحدد لكل جهاز على شبكة المعلومات والاتصالات.

طريقة تمثيل الـ IP address بالنظام الثنائي بـ 32 بت اسمها IPv4 — وهي بتتكتب في 4 خانات كل خانة 8 بت، مفصولة بنقطة (.)، وبتتكتب بالنظام العشري من 0 لـ 255.

فكّر فيها كده: IPv4 زي عنوان بيت من 4 أجزاء: شارع + حي + مدينة + محافظة — والأجزاء مفصولة بنقط زي 192.168.0.1.

📖 من الكتاب (بنصه)«أ. عناوين IP وأسماء النطاقات (1) عنوان (IP address): رقم تعريفي فريد يتم تعيينه لكل جهاز متصل بالإنترنت. وتُعرف طريقة تمثيل عنوان IP باستخدام النظام الثنائي (binary) باسم IPv4. • يتم تمثيله في أربع كتل من (8 bit) لكل منها، مفصولة بنقطة (.)، ومعبّر عنها في النظام العشري من 0 إلى (255).» الشكل المطبوع:ثنائي 32 بت «11000000.10101000.00000011.00000001» يقابل عشري «192.168.3.1».

الـ Global IP والـ Private IP (Global and Private)

على الإنترنت أو في الشبكة المحلية — بالكتاب

الـ Global IP address هو عنوان بيتستخدم على الإنترنت — وفريد ومش بيتكرر.

أما الـ Private IP address فهو عنوان بيتستخدم جوه الشبكة المحلية زي الـ LAN — وبيتقدر يستخدم بحرية في نفس الشركة.

فكّر فيها كده: العالمي زي رقم جواز سفر فريد في العالم كله، والخاص زي تحويلة تليفون داخلية ممكن تتكرر جوه كل شركة.

📖 من الكتاب (بنصه)«(2) عنوان Global IP وعنوان Private IP [1] عنوان IP العام (Global IP address): عنوان IP يُستخدم على الإنترنت. [2] عنوان IP الخاص (Private IP address): عنوان IP يُستخدم ضمن شبكة محلية، مثل LAN. (3) مشكلة نفاد عناوين IP:بسبب الانتشار السريع للإنترنت، لم يعد هناك تقريبًا عناوين IPv4 جديدة متاحة للتخصيص. لذلك، نحن ننتقل حاليًا إلى (IPv6)، الذي تم توسيعه إلى (128 bit).»

الـ Domain name (Domain Name)

اسم متعمول للبشر بدل الأرقام — بالكتاب

الـ Domain name هو سلسلة حروف بتتحدد عشان تخلّي رقم الـ IP أسهل في الفهم للبشر.

فكّر فيها كده: بدل ما نفتكر أرقام زي 203.216.206.63، بنفتكر اسم سهل زي example.com — الاسم ده هو اسم النطاق.

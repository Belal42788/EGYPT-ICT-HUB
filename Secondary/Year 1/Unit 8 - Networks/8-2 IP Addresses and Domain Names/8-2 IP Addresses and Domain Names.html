مقدمة الدرس — عناوين IP وأسماء النطاقات

الـ IP address (IP Address)

عنوان فريد لكل جهاز — صفحة 99 بالكتاب

الـ IP address هو رقم تعريف فريد زي العنوان بالظبط، بيتحدد لكل جهاز على شبكة المعلومات والاتصالات.

طريقة تمثيل الـ IP address بالنظام الثنائي بـ 32 بت اسمها IPv4 — وهي بتتكتب في 4 خانات كل خانة 8 بت، مفصولة بنقطة (.)، وبتتكتب بالنظام العشري من 0 لـ 255.

فكّر فيها كده: IPv4 زي عنوان بيت من 4 أجزاء: شارع + حي + مدينة + محافظة — والأجزاء مفصولة بنقط زي 192.168.0.1.

الـ Global IP والـ Private IP (Global and Private)

على الإنترنت أو في الشبكة المحلية — صفحة 99 بالكتاب

الـ Global IP address هو عنوان بيتستخدم على الإنترنت — وفريد ومش بيتكرر.

أما الـ Private IP address فهو عنوان بيتستخدم جوه الشبكة المحلية زي الـ LAN — وبيتقدر يستخدم بحرية في نفس الشركة.

فكّر فيها كده: العالمي زي رقم جواز سفر فريد في العالم كله، والخاص زي تحويلة تليفون داخلية ممكن تتكرر جوه كل شركة.

استنفاد العناوين والتحويل لـ IPv6 (Exhaustion and IPv6)

المشكلة والحل — صفحة 99 بالكتاب

علشان كده إحنا حاليين بنتحول لـ IPv6 — وهي عناوين IP تم توسيعها لـ 128 بت.

الـ Domain name (Domain Name)

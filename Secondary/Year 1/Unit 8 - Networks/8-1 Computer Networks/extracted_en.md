Lesson introduction — Computer Networks

Computer networks are how computers talk to each other and exchange data. Today we learn what a network is, its types LAN and WAN, the Internet, the devices we connect with like ISP, Router, and Hub, the Server and Client, and communication methods like Circuit switching and Packet switching.

Think of it this way:

A network is like a growing family: first they were together in one house (LAN), then they spread out and stayed connected everywhere (WAN), and in the end they all linked together (the Internet).

### ⚠️ Common Mistakes

Confusing LAN with WAN — LAN is for a limited area like home or school, and WAN is for a broader area.

Confusing the Router with the Hub — the router relays data between different networks, and the hub is a central device that connects many cables.

Types of Networks

LAN, WAN, and the Internet — book page 95

A Local Area Network (LAN) connects devices in a limited area, like a school or home — either wired (Wired LAN) with cables or wireless (Wireless LAN) using radio waves.

A Wide Area Network (WAN) connects a broader area. The Internet connects LANs and WANs on a global scale.

Think of it this way:

LAN is like the home network, WAN is like the whole governorate network, and the Internet is like the whole world connected.

from home to the world — LAN, then WAN, then the Internet

Connecting to the Internet

ISP, Router, and Hub — book page 95

To connect to the Internet we need: an ISP (provider), a company that facilitates the connection and we sign a contract with it, a Router, a device that relays data between different networks, and a Hub, a central device that connects many cables.

Think of it this way:

The ISP is like the electricity company that connects your service with a contract, the Router is like a mail distributor that delivers letters between places, and the Hub is like a connection board that gathers all the cables.

Server, Client, and Usage Patterns

network usage patterns — book page 95

A Server is a computer that provides various services — like a File server that manages files, a Printer server that handles print processing, a Mail server that handles sending and receiving emails, and a Proxy server that acts as an intermediary for accessing the Internet.

A Client is a computer that requests various services from a server. There are two patterns: the Client-server system where services are provided and received, and the Peer-to-peer system where computers are in an equal relationship, providing and receiving services.

Think of it this way:

The Server is like a restaurant that provides food, and the Client is like the customer who orders. In the peer-to-peer system, everyone is a chef and everyone eats at each other's place.

from the service provider to the one who requests it

the Server — provides the services

the Client — requests the services

Communication Methods

Circuit switching and Packet switching — book pages 95–96

The Circuit switching method is a communication method where a communication path is established between the sender and the recipient before starting the transmission to exchange information.

A Packet is a unit for dividing data into small chunks when transmitting over a network. The Packet switching method divides the data being transmitted into packets for exchange.

Think of it this way:

Circuit switching is like a phone call that holds the line until the conversation ends, and packet switching is like the mail that splits a book into chapters and sends each separately, then gathers them at the end.

from a full path to small packets

the Circuit switching — a fixed path before transmission

the Packet — dividing data into small chunks

the Packet switching — exchanging via packets

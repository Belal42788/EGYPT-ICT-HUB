Lesson introduction — modeling and types of models

In the world we see many phenomena, and models help us understand them: a model is a simplified representation of a target phenomenon, modeling is the process of creating models, and we classify models by characteristics (static/dynamic) and by expression (physical/diagrammatic/mathematical), and learn the modeling steps.

Think of it this way:

A model is like a mini version of something real so we can study and understand it easily — like a globe representing the Earth.

### ⚠️ Common Mistakes

Confusing the model with modeling — the model is the representation itself, and modeling is the process of creating it.

Confusing deterministic with probabilistic — deterministic has one result, probabilistic has more than one.

Confusing the reduced model with the enlarged one — the reduced is smaller than reality and the enlarged is bigger.

Classification by Characteristics

static and dynamic (deterministic and probabilistic) — book page 142

A static model is a model that does not undergo changes over time — like a room layout diagram and the relationship between the radius and volume of a sphere.

A dynamic model is a model influenced by changes over time — divided into two types: deterministic, which has only one result (like a bank account balance), and probabilistic, whose result is not a single outcome (like rolling dice).

Think of it this way:

Static is fixed like a picture, dynamic changes like a video — deterministic has a known end, and probabilistic involves luck.

Classification by Expression

physical, diagrammatic, and mathematical — book page 142

A physical model (scale model) is a physical representation of an object — enlarged (bigger than reality like a DNA model), full-scale (like a model room), or reduced (smaller than reality like a globe).

A diagrammatic model represents something using a diagram — like flowcharts and route maps. A mathematical model represents something using mathematical formulas or logical expressions — like speed × time = distance.

Think of it this way:

Physical is a tangible object, diagrammatic is a drawing, and mathematical is an equation.

Modeling Steps

three clear steps — book page 142

The modeling steps are three: (1) clearly define the purpose of modeling, (2) clarify the elements that constitute the model and their relationships, (3) determine the representation method of the model.

Think of it this way:

Before you build a model, ask yourself: what do you want to achieve? What are its components? And how will you draw it?

B  a deterministic model

The outcome of rolling dice belongs to which type of model?

A  a static model

B  a probabilistic model

C  a deterministic model

✅ Answer: B — a probabilistic model

Rolling dice has more than one possible outcome — irregular behavior.

The relationship between time and distance for a bicycle moving at a constant speed belongs to which type?

The speed is constant, so the distance is calculated — one result.

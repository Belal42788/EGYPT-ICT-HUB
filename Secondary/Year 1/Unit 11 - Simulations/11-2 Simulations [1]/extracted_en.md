Simulation: Predicting the Future with a Model

Simulation is manipulating a model in order to predict phenomena or events, and we use it even when it is difficult to use actual objects. In spreadsheet software we build models with formulas and change the inputs to see the predicted results.

Before simulating, we must know cell referencing — relative or absolute — so that formulas copy correctly.

Referencing Methods in Spreadsheet Software

In formulas that are copied, there are two referencing methods: relative and absolute, and we use the $ symbol to fix the cell.

Referencing Methods

Relative reference

The cell position changes automatically

Absolute reference

It fixes the row or column

The $ symbol

Adding it makes the reference absolute

Balance Simulation and Compound Interest

The compound interest method is a method in which the interest generated from the balance is incorporated into the balance itself for the next period. Interest = current balance × interest rate, and next period balance = current balance + interest.

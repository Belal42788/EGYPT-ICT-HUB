التفاعل وأدوار الملفات

نقطة الكتاب: استخدام الذكاء الاصطناعي التوليدي لبرمجة صفحات ويب ديناميكية (تفاعلية) باستخدام JavaScript.

ديناميكية هنا تعني تفاعلية: ضغطة تؤدي إلى تغيير في النص أو اللون. هذا لا يساوي بالضرورة توليد الصفحة على الخادم لكل طلب.

HTML للمحتوى، CSS للتصميم، و JavaScript للتفاعل في أمثلة هذا الدرس. الملفات منفصلة للتعلم والتعديل؛ ليست الطريقة الوحيدة الصحيحة لبناء المواقع.

طلب فصل الملفات الثلاثة صريح في الإنجليزية فقط. العربية لا تتضمن هذه الجملة. الإنجليزية تضيف أيضاً طلب شرح الكود وإعادة تسمية المحادثة؛ سنميزهما أدناه.

Bهم الاتنين ثابتة
Cالثابتة هي اللي بتتفاعل أكتر

Cبنطلب كود منفصل لـ HTML و CSS و JS

صف المطلوب: تعريف بالنفس وزر يغير الخلفية. طلب فصل الملفات موجود في الإنجليزية فقط؛ يمكن تطبيقه في التدريب الإضافي هنا.

ضع كل جزء في مكانه المناسب، وشغّل النتيجة ثم جرب الزر. الصورة مثال ناتج، وليست كوداً مطبوعاً يمكن نسخه.

تمهيد 3

قم بتعديل أكواد HTML و CSS و JavaScript لتغيير ألوان الخلفية المحددة مسبقاً، أو لزيادة تنوع الألوان المتاحة.

دوّن اللون المتوقع قبل الضغط، ثم قارن عدة ضغطات. المثال الإضافي يستخدم ثلاث حالات واضحة؛ عدل الألوان أو أضف حالة مع تحديث دورة العداد.

تمهيد 4

أعط الذكاء الاصطناعي الطلب التالي واقرأ الشرح: "اشرح هذا الكود."

هذا السطر في الإنجليزية فقط؛ العربية هنا ترجمة للمقارنة. اطلب شرح المتغير والمعالج وتغيير الخلفية، ثم تحقق بالتجربة. الشرح ليس ضماناً للصحة.

تمهيد 5

دليل إضافي، وليس مفتاح إجابة مطبوعاً.

دوّن جزءاً محدداً ومعناه الذي تتوقعه، ثم ارجع إلى توثيق موثوق واختبره. لا تعتبر الشرح المقنع وحده دليلاً.

تمرين 1

لنحاول إنشاء صفحات ويب تفاعلية لأغراض متنوعة باستخدام الذكاء الاصطناعي التوليدي، مثل: • تصنيف الرياضات الأكثر شعبية. • مطاعم موصى بها في [اسم المنطقة]. • تعريف بمدرستك [اسم المدرسة]. • أشهر المعالم السياحية في مصر... إلخ.

دليل إضافي، وليس مفتاح إجابة مطبوعاً.

اختر غرضاً وحدد التفاعل المطلوب، ثم خطط للمحتوى والتصميم والكود والاختبار. التصنيفات والتوصيات والمعالم تحتاج مصادر، ولا تثبتها بيانات التدريب.

عشر مهام عبر النسختين: ثماني مهام مشتركة، وسطران إضافيان في الإنجليزية فقط. علامات المراجعة ليست دليلاً على تنفيذ خارجي.

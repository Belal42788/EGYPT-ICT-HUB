إيه هو الـ HTML؟

HTML اختصار HyperText Markup Language، وهي لغة ترميز لبناء هيكل ومحتوى صفحة الويب، مثل العناوين والفقرات والجداول والقوائم. المتصفح يقرأ الترميز ويعرض الصفحة.

صفحة التعريف: كود الكتاب الكامل

سطور الكود لا تلتف؛ اسحب داخل الحقل أفقياً عند الحاجة.

المعاينة تظهر آخر تشغيل فقط. تعديل الكود لا يشغله تلقائياً.

تحتوي العناصر مثل h1 على وسم بداية ومحتوى ووسم نهاية. عناصر فارغة مثل meta و link لا تملك وسم نهاية. بعض وسوم النهاية يمكن حذفها في حالات محددة؛ ليست القاعدة أن كل وسم مفتوح يُغلق دائماً.

⚠️أخطاء شائعة
  • الخلط بين قواعد العناصر: راجع وسوم h1 و title، ولا تضف وسم غلق إلى meta أو link.
  • كتابة DOCTYPE غلط , ده أول سطر في الصفحة.

CSS اختصار Cascading Style Sheets. تصف تصميم الصفحة، مثل لون النص وحجمه ونوع الخط ولون الخلفية. المحدد يختار العناصر، والتصريح يربط خاصية بقيمة داخل الأقواس.

المعاينة تظهر آخر تشغيل فقط. تعديل الكود لا يشغله تلقائياً.



شكل الكتاب يحتوي على العنوان My page والفقرتين HELLO و WORLD. قاعدة p { color:red; } تطابق الفقرتين وتجعلهما بالأحمر، من غير تغيير العنوان.
صفحة التعريف وملف style.css
سطور الكود لا تلتف؛ اسحب داخل الحقل أفقياً عند الحاجة.
المعاينة تظهر آخر تشغيل فقط. تعديل الكود لا يشغله تلقائياً.



الفئة class ليست اسماً فريداً بالضرورة. قد تشترك عناصر متعددة في class واحد، والمحدد.name يطابق كل عنصر يحمل هذه الفئة، حتى لو اختلف نوع الوسم. المحدد p يطابق عناصر p. وقد تؤثر قواعد أخرى في اللون النهائي.


اختلاف مصدر مهم:الكود العربي يكتب Adam، والإنجليزي يكتب Ichiro، لكن لقطات الناتج في الكتاب الإنجليزي تعرض Adam. بعض لقطات البداية في الكتابين تعرض أيضاً نصوص وسوم شاردة. المعاينة هنا تنفذ الكود نفسه: الاسم من h1، من غير تلك النصوص الشاردة. المثال الأزرق يغير اللون فقط؛ الحجم والخط في مهمة جرب.

أنشطة الكتاب كاملة
تجمع صياغة الإحماء التعليمات المحيطة بالكود عبر الصفحات. جميع ملفات الكود كاملة في المحررين المرتبطين. المهام مفتوحة، بلا إجابة وحيدة أو درجة تلقائية. الأدلة الإضافية أمثلة وليست مفتاحاً مطبوعاً.
إحماء 1: صفحة التعريف
لنكتب صفحة بسيطة للتعريف بنفسك باستخدام HTML. انسخ أو اكتب الكود الكامل في WebDen ثم اضغط Run. ستظهر صفحة تعرض الاسم المكتوب.
افتح المحرر المرتبط
الكود العربي يعرض Adam، والإنجليزي يعرض Ichiro. عنوان المتصفح About Me، أما عنوان الصفحة الظاهر فهو محتوى h1. راجع ملاحظة اختلاف لقطة الكتاب.
إحماء 2: ملف HTML وملف CSS
بعد ذلك غيّر لون النص وحجمه باستخدام CSS. انسخ أو اكتب كود HTML المرتبط بملف style.css وكود CSS في WebDen ثم شغلهما. يتحول النص إلى الأزرق.
افتح المحرر المرتبط
المثال المطبوع.name { color:blue; } يغير اللون فقط. تغيير الحجم والخط مطلوب في جرب أدناه. يجب أن يتطابق class="name" مع المحدد.name. قد يشترك أكثر من عنصر في نفس class.
جرب 1: محتوى إضافي
لنحاول إضافة عناصر إضافية للعرض.
افتح المحرر المرتبط
المهمة مفتوحة. مثال إضافي ممكن:<p>My hobby is reading.</p>. راجع ترتيب العناصر والوسوم المطلوبة، ولا تعتبر ظهور الصفحة دليلاً على صحة كل الصياغة؛ المتصفح قد يصلح بعض الأخطاء.
جرب 2: حجم النص والخط
لنجرّب تغيير حجم الخط ونوعه.
افتح المحرر المرتبط
مثال إضافي، وليس كوداً مطبوعاً في الكتاب:.name { color: blue; font-size:40px; font-family:serif; }. اختر حجماً وخطاً مناسبين لهدفك. الخط الفعلي يعتمد على الخطوط المتاحة محلياً.
تمرين: صفحة لموضوع مختلف
لنحاول إنشاء صفحة ويب لموضوع آخر غير التعريف بالنفس.
افتح المحرر المرتبط
لا توجد صفحة واحدة نموذجية أو درجة تلقائية. مثال موضوع ممكن: نادي القراءة أو معرض أعمال فني. تحقق من أن المحتوى والتصميم يخدمان الموضوع، وأن أسماء الملفات والمحددات متطابقة.

قاموس المصطلحات
HTML
لغة الترميز، HyperText Markup Language
لغة تصف هيكل ومحتوى الصفحة.
جرب المصطلح
CSS
أوراق الأنماط، Cascading Style Sheets
لغة لتصميم الصفحة، مثل اللون والحجم والخط.
جرب المصطلح
Tag / Element
وسم، عنصر
الوسوم تحدد العنصر ومحتواه؛ h1 عنوان و p فقرة.
جرب المصطلح
Void element
عنصر فارغ
عنصر مثل meta أو link لا يملك وسم نهاية.
جرب المصطلح
DOCTYPE
تصريح نوع المستند
<!DOCTYPE html> تصريح لنوع مستند HTML، وليس عنصراً عادياً بوسمي بداية ونهاية.
جرب المصطلح
Attribute
خاصية عنصر، سمة
معلومة في وسم البداية، مثل class و href؛ ليست هي خاصية CSS مثل color.
جرب المصطلح
Class
فئة، class="name"
فئة يمكن أن تشترك فيها عناصر متعددة. المحدد.name يختارها.
جرب المصطلح
Selector
محدد،.name، p
جزء من قاعدة CSS يحدد العناصر التي تطابقها.
جرب المصطلح
Property / Value
خاصية CSS، قيمة، تصريح
في color:red; الخاصية color والقيمة red.
جرب المصطلح
Style sheet
ورقة أنماط، ملف CSS
ملف قواعد CSS؛ اسم الملف في الكتاب style.css.
جرب المصطلح
link / href
ربط الملف، rel="stylesheet"
link يربط ورقة الأنماط؛ href يحدد مسارها.
جرب المصطلح
Web browser

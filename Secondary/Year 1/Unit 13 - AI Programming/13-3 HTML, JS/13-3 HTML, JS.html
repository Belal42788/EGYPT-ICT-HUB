الأزرار والأحداث

بنربط الأزرار بدوال بتشتغل اللحظة اللي المستخدم يضغط عليها.

⚠️أخطاء شائعة
  • الخلط بين HTML اللي بيعرض المحتوى و JavaScript اللي بيغيّره.
  • افتراض أن JavaScript تعمل في المتصفح فقط. نستخدمها هنا في المتصفح، لكنها تعمل أيضاً خارجه، مثل Node.js على الخادم.

المعاينة نموذج تعليمي محلي: عناصر نص وقوائم وأزرار، و getElementById و textContent و onclick و const/let ودوال سهمية بلا معاملات و if والمقارنات والدمج وبعض خصائص style. لا تدعم الحلقات أو الاستيراد أو الشبكة أو النوافذ أو HTML الخام أو واجهات JavaScript الأخرى. لا تنفذ كودك على الصفحة المضيفة ولا ترسله إلى WebDen. الملفات الخارجية وسمات الأحداث في HTML مهملة.
يمكن تعديل الكود والملاحظات وتبديل اللغة من غير فقدها. الكود الافتراضي غير المعدل يتبع النسخة المختارة. إعادة الضبط تمسح تعديلات ذلك المحرر فقط. لا تُحفظ الملاحظات والكود بعد إعادة تحميل الصفحة. حدود النموذج: HTML 20000 حرف، و JavaScript 8000، و500 عنصر، وعمق HTML 32 و AST 40، و2000 خطوة لكل تشغيل أو ضغطة، و8 استدعاءات متداخلة.

إيه هو الـ JavaScript؟

JavaScript لغة برمجة تضيف تفاعلاً إلى صفحات الويب، فتغير النصوص أو التصميم استجابةً لأفعال المستخدم. ليست الحركة وحدها وظيفتها، وليست محصورة في المتصفحات.

شكل الكتاب: تغيير فقرة واحدة

نموذج محدود، وليس JavaScript كاملاً. اضغط الأزرار داخل المعاينة بعد التشغيل. تعديل الكود لا يحدث النتيجة تلقائياً. سطور الكود تنزلق أفقياً داخل الحقل.

في المثال اللي فوق، اتحدد id لوسم p في HTML، و JavaScript استخدمت الـ id ده عشان تغيّر النص جوه الوسم. .textContent بيتستخدم لما نحدد (أو نقرأ) النص جوه أي وسم.

⚠️أخطاء شائعة
  • كتابة id مختلف بين HTML و JavaScript , لازم يكون نفس الاسم.
  • استخدام textContent على عناصر مش نص زي الصور , مش هيشتغل.

تغيير النص بـ textContent

نضع id فريداً داخل المستند، ثم نبحث عنه بـ document.getElementById. البحث يراعي الحروف الكبيرة والصغيرة ويعيد null إذا لم يجد العنصر. نقرأ النص أو نغيره بـ textContent، كنص عادي لا كـ HTML.

تغيير الاسم فور التشغيل

نموذج محدود، وليس JavaScript كاملاً. اضغط الأزرار داخل المعاينة بعد التشغيل. تعديل الكود لا يحدث النتيجة تلقائياً. سطور الكود تنزلق أفقياً داخل الحقل.

  • النسيان إن في علامات اقتباس حوالين النص اللي بتعيّنه في textContent.

تغيير الاسم عند الضغط

نموذج محدود، وليس JavaScript كاملاً. اضغط الأزرار داخل المعاينة بعد التشغيل. تعديل الكود لا يحدث النتيجة تلقائياً. سطور الكود تنزلق أفقياً داخل الحقل.

تغيير الحجم عند الضغط

نموذج محدود، وليس JavaScript كاملاً. اضغط الأزرار داخل المعاينة بعد التشغيل. تعديل الكود لا يحدث النتيجة تلقائياً. سطور الكود تنزلق أفقياً داخل الحقل.

في المثال ده بنستخدم onclick: لما المستخدم يدوس الزر، الكود اللي جوه الوظيفة بيتنفّذ ويغيّر النص. جرب كمان تغيير حجم الخط بـ style.fontSize.

  • تكتب onclick = () => { } من غير الأقواس المعقوصة , مش هتشتغل.
  • تنسى علامة = في text.style.fontSize = 50 + "px".

أنشطة الكتاب كاملة
أول ثلاث مهام تجمع التعليمات والكود والنتيجة عبر صفحات الإحماء، ولا تدعي أنها اقتباس متصل. مهام جرب والتمرين مفتوحة بلا إجابة وحيدة أو درجة تلقائية. الأدلة والأمثلة المضافة ليست مفتاحاً مطبوعاً.
إحماء 1: تغيير النص فوراً
لنحاول تعديل صفحة التعريف بالنفس باستخدام JavaScript. انسخ أو اكتب كود HTML وكود JavaScript في WebDen وقم بتشغيله. لاحظ تغير الاسم.

العربي: Adam ثم Omar. الإنجليزي: Ichiro ثم Ohtani. التغيير فوري عند التشغيل، وليس بعد ضغط زر. ملف style.css مرتبط في المصدر لكن هذه الصفحات لا تقدم له كود CSS.
إحماء 2: تغيير النص بزر
بعد ذلك، لنجرب تغيير النص من خلال النقر على زر. انسخ أو اكتب الكود في WebDen وشغله، ثم اضغط الزر ولاحظ تغير الاسم.
افتح المحرر المرتبط
التشغيل يجهز مرجع العنصر ومعالج onclick. جسم الدالة السهمية ينتظر الضغط: Adam إلى Omar بالعربي، و Ichiro إلى Ohtani بالإنجليزي.
إحماء 3: تكبير النص بزر
لنحاول تغيير حجم النص. انسخ أو اكتب الكود في WebDen وشغله، ثم اضغط الزر. سيصبح حجم خط الاسم أكبر.
افتح المحرر المرتبط
50 + "px" تنتج النص "50px"، وهو طول CSS. يتغير الحجم إلى 50px بعد الضغط فقط، بينما يبقى الاسم كما هو.
جرب 1: اللون والحجم معاً
لنحاول جعل لون النص وحجمه يتغيران معاً عند الضغط على الزر.
افتح المحرر المرتبط
دليل إضافي، وليس مفتاحاً مطبوعاً: ضع text.style.color = "red"; و text.style.fontSize = 50 + "px"; داخل نفس الدالة. اختر لوناً وحجماً مناسبين.
جرب 2: دمج نصي عنصرين
لنضف عنصراً جديداً للعرض، ولنحاول إنشاء دالة تقوم بدمج نصوص العنصرين معاً عند النقر على الزر.
افتح المحرر المرتبط
مثال إضافي كامل متاح بزر تحميل مثال المهمة. النتيجة تعتمد على نصيك؛ الجمع + يدمج النصوص. استخدام فاصل مثل " " يمنع التصاق الكلمتين. لا تستبدل النص بـ HTML.
تمرين: تناوب الأحمر والأزرق
لنحاول جعل لون النص يتبادل بين اللونين الأحمر والأزرق في كل مرة يتم فيها الضغط على الزر.

حل إضافي ممكن داخل onclick:text.style.color = text.style.color === "red"? "blue": "red";. عند البداية بلا لون inline تكون الضغطات red ثم blue ثم red. style.color يقرأ لون inline، وليس بالضرورة اللون المحسوب من كل CSS.

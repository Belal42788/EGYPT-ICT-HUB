Developing a Quiz App

الدرس السابع من وحدة البرمجة بالذكاء الاصطناعي — هنطلب من الـ AI تطبيق اختبار بـ JavaScript ونطوّره من سؤال واحد لـ 3 أسئلة.

1

هنتعلم إيه النهارده؟

النهارده هنجيب من الذكاء الاصطناعي كود تطبيق اختبار (Quiz App) بسيط بـ JavaScript — سؤال واختيارات، وبعدين نطوّره لـ 3 أسئلة ونظبطه على ذوقنا.

🤖

نطلب التطبيق من الـ AI

بنكتب prompt يخلّي الـ AI يعمل تطبيق اختبار من سؤال واحد.

🧩

نشغّل الكود في WebDen

بنلزق الكود في تبويبات HTML و CSS و JavaScript ونشغّله.

⚙️

نطوّر التطبيق

نغيّر السؤال والإجابات، ونزوّد الأسئلة لـ 3، ونضيف مزايا جديدة.

⚠️أخطاء شائعة
  • تظن إن الـ AI هيعطي نفس الكود كل مرة — النتيجة بتتغير كل مرة.
  • تطلب التطبيق من غير ما تطلب فصل الكود HTML و CSS و JS.
2

إيه تطبيق الاختبار؟

تطبيق الاختبار بيورّي المستخدم سؤال بخيارات، وبعد ما يختار بيقوله إجابته صح ولا غلط. بيتكتب بـ HTML للهيكل و CSS للشكل و JavaScript للمنطق.

JavaScript هي اللي بتقارن الإجابة المختارة بالإجابة الصحيحة وتورّي النتيجة.

لما نطلب من الـ AI، لازم نقول له: Create a simple multiple-choice quiz app. Include only one question. Please provide separate code for HTML, CSS, and JavaScript.

⚠️أخطاء شائعة
  • تنسى تحديد عدد الأسئلة في الطلب الأول — بنحدد سؤال واحد.
  • تنسى طلب فصل الكود HTML و CSS و JavaScript.

3

تطبيق الاختبار بسؤال واحد

بعد ما الـ AI يدينا الكود، بنلزقه في تبويبات HTML و CSS و JavaScript في WebDen ونشغّله. الكود اللي جوه مثال واحد — الـ AI بيديك كود مختلف كل مرة.

مثال: اختبار بسؤال واحد
دوس Run بعدين اختار إجابة — التطبيق يقولك صح ولا غلط.

ممكن نعدّل كود HTML و CSS و JavaScript عشان نغيّر نص السؤال أو الإجابة الصحيحة. وبعدين نطلب من الـ AI: Explain this code عشان نفهم الكود.

⚠️أخطاء شائعة
  • تنسى تحديث المتغير correct لما تغيّر الإجابة الصحيحة.
  • تسيب الكود من غير ما تطلب Explain this code عشان تفهمه.

Cالكود من الكتاب

4

نطوّره لـ 3 أسئلة

الخطوة الجاية: نطلب من الـ AI prompt جديد: Make it 3 questions. الـ AI هيكتب كود بيعرض الأسئلة واحد واحد وبيحسب النتيجة في الآخر.

مثال: اختبار بـ 3 أسئلة
دوس Run واجاوب على الأسئلة التلاتة — النتيجة بتتحسب في الآخر.

لاحظ إن الكود بقى بيستخدم array من الأسئلة، و index عشان يتنقل بينهم، و score عشان يحسب النتيجة. تعديل عدد الأسئلة سهل: نزوّد العناصر في الـ array.

⚠️أخطاء شائعة
  • تنسى تزوّد مؤشر الإجابة الصحيحة (a) لما تضيف سؤال جديد.
  • تنسى إن index لازم يتقدم بعد كل إجابة عشان السؤال يتبدل.

Exercise — صفحة 193

1 إزاي نزوّد عدد الاختيارات؟
A  بنضيف وسوم خيارات جديدة في HTML ونحدّث الـ array
الاجابة: بنضيف وسوم خيارات (opt) في HTML ونضيف الخيارات الجديدة في الـ array، ونظبط مؤشر الإجابة الصحيحة.
2 إزاي نعرض نسبة الإجابات الصحيحة؟
A  بنحسب score ÷ عدد الأسئلة × 100
الاجابة: بنقسم عدد الإجابات الصحيحة (score) على عدد الأسئلة ونضرب في 100، ونعرض النسبة على الشاشة.
3 إزاي نخلّي ترتيب الأسئلة عشوائي؟
A  نخلط الـ array باستخدام Math.random
الاجابة: بنخلط ترتيب الـ array بتاعة الأسئلة باستخدام Math.random (أو مكتبة shuffle) عشان الأسئلة تيجي بترتيب مختلف كل مرة.

Variance and Standard Deviation
・ Variance and standard deviation: These represent numerically how much the data is spread out from the
mean (1mean). Let x1, x2, …, xn represent the values of the data. x refers to the mean, and n refers to the
number of data points.
(1) (2Deviation) : x1 - x, x2 - x, …, xn - x
(2) (3Variance) : The mean value of (x - x )². The (4larger) the variance, the more dispersed the data is.
 In Google Sheets, the VARP function can be used to determine variance, while in Excel,
the VAR.P function is used.
(3) (5Standard deviation) : s = √Variance
In spreadsheet software, the STDEV.P function can be used to determine the variance.
The standard deviation should be expressed in the same unit as the data.

What will we learn today?

Lesson introduction — quartiles and box-and-whisker plots

After learning the measures, now we learn a more complete way to describe a data distribution: the quartiles, which divide the data into four equal parts, and the box-and-whisker plot, which combines the five values (minimum, maximum, and quartiles) into a single figure.

Think of it this way:

The quartiles are like kilometer markers that divide the data into four stations, and the box-and-whisker plot is a map that shows all these stations in a single drawing.

### ⚠️ Common Mistakes

Confusing quartiles with quarters — quartiles are numbers that divide the data, not parts that have exactly the same number of elements.

Forgetting that the second quartile is the median — the first division applies the median concept twice.

When drawing the box-and-whisker plot, forgetting that the box's left edge is the first quartile, the right edge is the third quartile, and the whiskers extend to the minimum and maximum.

Quartiles

numbers that divide the data into four equal parts — book page 131

The quartiles are the numbers that divide the data into four equal parts when arranged in ascending order.

In ascending order we call them: the first quartile, the second quartile, and the third quartile — and the second quartile is the median.

Think of it this way:

Just as a field is divided into four equal quarters by lines, the quartiles divide the data into four equal parts with three numbers.

Steps for Determining the Quartiles

order, split, and determine the median — book page 131

To determine the quartiles we go through three steps — and in each step we apply the median idea.

Step one: arrange the data in ascending order and determine the median. Step two: with the median as the boundary, we divide the data into two groups — a group less than or equal to it and a group greater than or equal to it. Step three: determine the median of each group to get the first and third quartiles.

Think of it this way:

Example: the data 20, 32, 36, 38, 43, 47, 52, 58, 61, 72 — the median = (43 + 47) ÷ 2 = 45, the median of the lower group = 36 (first quartile), and the median of the upper group = 58 (third quartile).

Box-and-Whisker Plots

a box and lines displaying the five values — book page 131

A box-and-whisker plot is a figure using a box and lines (whiskers) to represent the minimum value, the first, second, and third quartiles, and the maximum value in a single figure.

The box represents the middle of the data (between the first and third quartiles), and the whiskers extend to the minimum and maximum values.

Think of it this way:

The plot is like a profile picture of the data — the box shows the half of the data in the middle, and the whiskers show the extreme values.

Steps to Draw the Plot

five lines, a box, and whiskers — book page 131

To draw a box-and-whisker plot we go through three steps.

We determine the minimum and maximum values and the quartiles, and draw five vertical lines representing the points — then draw a box with the first quartile as the left edge and the third quartile as the right edge — then draw a horizontal line from each end of the box to the minimum and maximum values.

Think of it this way:

The plot can also be drawn vertically — the same idea but arranged vertically.

### ✍️ Exercise 4: Reading a Box-and-Whisker Plot

A plot shows the daily number of customers at 4 stores over 31 days — which store exceeded 450 customers?

A  store A and store B

B  store C and store D

C  store A only

✅ Answer: B — store C and store D

These are the stores whose maximum value in their plot exceeded 450.

At store B, the number of days with more than 300 customers is what?

A  8 days

B  24 days

C  16 days

✅ Answer: C — 16 days

The median is the 16th value — so from day 16 to day 31 the customers exceeded 300 = 16 days.

A  store B

B  store A

C  store C

✅ Answer: B — store A

The first quartile is the 8th value — if it is less than 250, then there are 8 or more days below 250.

إيه اللي هنتعلّمه النهارده؟

النهارده هنعرف الدوال (Functions) في بايثون — دي حاجة بنعرفها مرة ونستخدمها كتير، بتاخد قيم (Arguments) وترجّع نتيجة (Return value).

🧩

الدالّة (Function) هي إيه

مجموعة عمليات في وحدة واحدة مسمّاة نقدر نستدعيها.

🎯

المُعامل والإرجاع (Argument and return)

الدالة بتاخد مدخلات وترجّع نتيجة عن طريق return.

⚙️

جاهزة ومعرّفة من المستخدم (Built-in and user-defined)

في دوال جاهزة زي print، ودوال بنعرّفها إحنا بـ def.

⚠️أخطاء شائعة
  • لازم تعرّف الدالة بـ def الأول قبل ما تناديها.
  • لو الدالة وصلت للنهاية بدون return بقيمة، بترجع None.

مفهوم Function

مصطلحات الكتاب:Argument للمتغير داخل التعريف وللقيمة المرسلة. الأدق: parameter هو اسم الاستقبال، وargument هي قيمة الاستدعاء. الدالة ممكن ما تاخدش مدخلات، ولو مفيش return بقيمة بترجع None. print بتعرض نص، وreturn بترجع قيمة للمنادي.

معمل التعريف والاستدعاء

غيّر القيمة، وتوقّع القيمة الراجعة، وبعدين امشِ خطوة بخطوة. تعريف الدالة لوحده مش بينفّذ جسمها.

          الدالة (Function) هي مجموعة عمليات محطوطة في وحدة واحدة. بنعرّفها بكلمة def،
          والمتغير اللي بياخد قيمة جوه الدالة اسمه Argument، وبأمر return بنبعت نتيجة
          العملية للمنادي كقيمة راجعة (Return value). ولما نستخدم الدالة بنعمل عملية استدعاء
          (Call) لها.

        
المحررات نموذج تعليمي محدود، مش Python كاملة. بتدعم دوال الدرس، معاملات موضعية، متغيرات محلية، return، شرط وحلقات. مفيش import أو معاملات افتراضية أو مسمّاة لدوال المستخدم. الحد20000 خطوة، و40 استدعاء متداخل، و2000 عنصر للقائمة أو range.

          
          

            
            
            الدالة بتاخد x = 5 وترجّع y = 2 × 5 = 10.
          

          

          

        

        
الكتاب كاتب ناتج مساحة المثلث 25. في Python3 العملية / بترجع float، فالمحرر بيطبع 25.0. القيمة العددية واحدة لكن شكل الناتج مختلف.

          
          

            
            
            دالة بمعاملَين: area(10, 5) = 10 × 5 / 2 = 25.
          

          

          

        

        

          في نوعين من الدوال: دوال مدمجة (Built-in functions) جاهزة نستخدمها من غير تعريف زي
          print و len و int، ودوال معرفة من
          المستخدم (User-defined functions) بنعرّفها إحنا بكلمة def.

        

          
          

            
            
            دالة فيها شرط if/else — judge(40) بتطبع Fail.

قاموس وتجارب
Function / الدالة
وحدة عمليات قابلة للاستدعاء. التعريف مش تنفيذ الجسم.
جرّب المفهوم
Parameter / معامل شكلي
اسم المتغير في تعريف الدالة، زي x. الكتاب بيسميه Argument.
جرّب المفهوم
Argument / وسيطة
القيمة المرسلة وقت الاستدعاء، زي 5.
جرّب المفهوم
def / تعريف
كلمة بتبدأ تعريف دالة، وبعد التوقيع نقطتين وجسم بمسافة بادئة.
جرّب المفهوم
Call / استدعاء
طلب تنفيذ الدالة باسمها وأقواس الاستدعاء.
جرّب المفهوم
return / إرجاع
ينهي استدعاء الدالة الحالي ويرجع قيمة للمنادي.
جرّب المفهوم
Return value / قيمة إرجاع
القيمة اللي المنادي بيستقبلها. مختلفة عن النص المطبوع.
جرّب المفهوم
None / لا قيمة محددة
قيمة الإرجاع لو مفيش return بقيمة؛ print بترجعها برضه.
جرّب المفهوم
Built-in function / دالة مدمجة
جاهزة بدون تعريف منك، زي print وlen.
جرّب المفهوم
User-defined function / دالة معرفة من قبل المستخدم
دالة انت بتعرّفها بـ def.

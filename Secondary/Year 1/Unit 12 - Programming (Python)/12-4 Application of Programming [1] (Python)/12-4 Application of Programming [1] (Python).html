النهارده هنتكلم عن القوائم (Lists) في بايثون — دي الحاجة اللي بتحفظ أكتر من قيمة في متغير واحد، وتخلي البرنامج يشيل بيانات كتير ويفصل فيها بسهولة.

القائمة (List) هي إيه

مجموعة مرتّبة من عناصر الداتا (Data) المتحفوظة في متغيّر واحد.

🔢

العنصر والرقم (Element and Index)

كل قيمة في القائمة ليها رقم موقع (index) بيبدأ من الصفر.

🧱

قائمة ثنائية الأبعاد (Two-dimensional list)

قائمة جوهها قوائم، بنوصل للعنصر بـ a[i][j].

⚠️أخطاء شائعة
  • الفهرس بيبدأ من صفر مش من واحد — a[0] هي أول عنصر.
  • أول ما تبدأ القائمة بتتبني وهي فاضية []، الإضافة اختيارية.

القائمة (List) هي مجموعة من عناصر البيانات مرتبة في تسلسل، وبنقدر ندير البيانات كلها مع بعض كمجموعة واحدة. بنعرّفها بإننا نكتب اسم القائمة وعلامة = ودي الأقواس الحاضنة [] ونحط جواها القيم مفصولة بفواصل.

المحررات نموذج تعليمي محدود، مش بايثون كاملة. بتدعم أمثلة الدرس: قوائم متداخلة، append، فهرسة، حلقات وشرط وطباعة. مفيش استيراد أو تعديل عنصر بـ a[i] = ... هنا. الحد 2000 عنصر للقائمة أو range و20000 خطوة. لو تجاوزته صغّر المثال أو استخدم بايثون كاملة.

جرّب تكتب قائمة أرقام أو أسماء وتحطها في print.
⚠️أخطاء شائعة
  • نسيان الأقواس [] أو الفاصلة بين القيم — القائمة مش هتتعرّف صح.
  • القيم النصية بين علامتي اقتباس '...'.

i / j012

              القائمة ثنائية الأبعاد بتدير البيانات بفهرس صف وفهرس عمود: a[i][j].
            

          

        

        

          القائمة ثنائية الأبعاد هي قائمة جوهها قوائم، بتخزّن البيانات في صفوف وأعمدة. بنعرّفها بإننا نكتب
          قوائم جوه القائمة الكبيرة، وبنوصل للعنصر الموجود في الصف i والعمود
          j بالصيغة a[i][j].

        

          
          

            
            
            a[0][0] = 'A' و a[1][2] = 'F'.
          

          

          

        

        

          
⚠️أخطاء شائعة

          
    
            
  • في a[i][j]، i هي رقم الصف و j هي رقم العمود — متقلبهمش.
    • 
            
  • القائمة ثنائية الأبعاد ليها فهرسين، مش فهرس واحد زي القائمة العادية.

قاموس وتجارب
List / Array / قائمة / مصفوفة
مجموعة مرتبة قابلة للتغيير. نوعها هنا list؛ راجع معمل القائمة.
جرّب المفهوم
Element / عنصر
قيمة داخل القائمة. اكشف عنصرًا في المعمل.
جرّب المفهوم
Index / فهرس
موضع العنصر؛ أول موضع 0. جرّب الفهرس -1 لآخر عنصر.
جرّب المفهوم
append / إضافة
طريقة تضيف عنصرًا واحدًا للنهاية وتعيد None. جرّب زر append.
جرّب المفهوم
Empty list / قائمة فارغة
[] قائمة بلا عناصر. مش لازم نضيف لها. جرّب [] في المحرر.
جرّب المفهوم
Two-dimensional list / مصفوفة ثنائية الأبعاد
قائمة تحتوي قوائم. a[i][j] يحدد الصف ثم العمود.
جرّب المفهوم
Row / صف
القائمة الداخلية؛ فهرسها i في المثال.
جرّب المفهوم
Column / عمود
موضع داخل الصف؛ فهرسه j في المثال.
جرّب المفهوم
range / تتابع
قيم صحيحة بحد توقف غير شامل. جرّب حلقة المحرر.
جرّب المفهوم
Traversal / مرور على العناصر
حلقة تمر على العناصر. الحلقات المتداخلة تعرض الصفوف ثم الأعمدة.
جرّب المفهوم
Minimum / أصغر قيمة
ابدأ بأول عنصر في قائمة غير فارغة، ثم قارن.
جرّب المفهوم
Maximum / أكبر قيمة
ابدأ بأول عنصر لو القيم ممكن تكون سالبة.
جرّب المفهوم
Sum / مجموع
ابدأ بـ 0، وأضف كل عنصر للمجموع.
جرّب المفهوم
Count / عدّ
ابدأ بـ 0، وزوّد 1 لكل عنصر يحقق الشرط.

جملة for والحلقة (looping)

عبارة for تكرر كتلة الأوامر ذات المسافة البادئة مرة لكل قيمة في range. الصياغة: for variable in range(...): ثم جسم الحلقة. لو المدى فارغ لن يُنفّذ الجسم.

دالّة range() بتحدّد المدى للمتغيّر. ليها تلات أشكال: range(end) وrange(start, end) وrange(start, end, increment).

أشكال range()

↔ مرّر الجدول أفقياً لرؤية الأعمدة كاملة.

أسلوب الكتابة المعنى
range(end)تبدأ من 0 بخطوة 1، وتتوقف قبل end. إذا كانت end أقل من أو تساوي 0 فالمدى فارغ.
range(start, end)تبدأ من start بخطوة 1، وتتوقف قبل end. قد يكون المدى فارغاً.
range(start, end, increment)تبدأ من start وتتحرك بمقدار increment. النهاية end غير مشمولة: أقل منها للخطوة الموجبة، وأكبر منها للسالبة. الخطوة 0 غير مسموحة.

توضيح للمصدر: عبارة end - increment في الجدول المطبوع ليست قاعدة عامة لآخر قيمة. مثلاً range(1, 8, 3) تعطي 1، 4، 7، وليس آخرها 5. ويستخدم Python الاسم stop للنهاية وstep للخطوة.

المشغّل هنا نموذج تعليمي محدود، وليس Python كاملاً. يدعم أمثلة الدرس: قيم صغيرة، print وrange وحلقات for وفروع if/elif/else بمسافات بادئة. حدوده للحماية: 2000 قيمة لكل range و20000 خطوة تنفيذ. لا يدعم imports أو تعريف الدوال. للتجارب العامة استخدم Python الحقيقي.

عوامل المقارنة (Comparison Operators)

بتستخدم لمقارنة القيم

مقارنة القيم

عامل المقارنة بيستخدم لمقارنة تعبيرات أو قيم. النتيجة صح لو الشرط يتحقق، أو غلط لو لأ.

جدول عوامل المقارنة

↔ مرّر الجدول أفقياً لرؤية الأعمدة كاملة.

العامل المعنى مثال
==يساويx == 70x تساوي 70
!=لا يساوي (مش يساوي)x != 70x لا تساوي 70
<أصغر منx < 70x أصغر من 70
>أكبر منx > 70x أكبر من 70
<=أصغر من أو يساويx <= 70x أصغر من أو تساوي 70
>=أكبر من أو يساويx >= 70x أكبر من أو تساوي 70

🎮 توقّع نتيجة المقارنة

جرّب العوامل الستة. اختر True أو False، ثم غيّر القيم واختبر فهمك.

⚠️ أخطاء شائعة

  • الخلط بين = (تعيين) و== (مقارنة): == بتسأل «هل هما متساويين؟».
  • استخدام = واحدة جوه الشرط بدل == — ده هيعمل غلط.

عبارات التفرع if / elif / else

عبارة if تختبر تعبيراً شرطياً لاختيار فرع. المقارنات في الدرس تعطي True أو False. لا تخلط بين عبارة if وبين التعبير المقارَن مثل x >= 60.

if لوحدها لما الشرط يتحقق، وif ~ else لما عايزين كمان إيه هيحصل لو ماتحققش، وif ~ elif ~ else عشان نتحقق من شروط متعدّدة بالترتيب.

مثال الكتاب: if مع else، نجاح أو رسوب.

pass_fail.py
النتيجة Pass. غيّر x إلى 59 وجرّب فرع else.
grade.py
النتيجة: الدرجة B (لأن 70 >= 50)

⚠️ أخطاء شائعة

  • النسيان إن في نقطتين (:) بعد if وelif وelse.
  • النسيان إن في مسافة بادئة قبل الكود جوه الفرع.
  • في مثال التقديرات مع >= اختبر 90 قبل 50، لأن أي درجة تصل إلى 90 تحقق الشرط >= 50 أيضاً.

مصطلحات الدرس (Lesson Terms)

دوّر على أي مصطلح أو استخدم الفلاتر عشان تضيّق.

عبارة for · جملة for (for statement)

عبارة تكرر كتلة بمسافة بادئة، مرة لكل قيمة في المدى.

range()

تحدد البداية والنهاية غير المشمولة والخطوة. الخطوة السالبة تعد تنازلياً، و0 غير مسموحة.

هيكل الحلقة · حلقة (Loop Structure)

عامل بيقارن القيم، زي == و!= و< و> و<= و>=.

التعبير الشرطي (Conditional Expression)

أصغر من أو يساوي (<=)

عامل مقارنة. جرّبه في لعبة المقارنة.

أكبر من أو يساوي (>=)

عامل مقارنة. جرّبه في لعبة المقارنة.

قيمة البداية (Start value)

بداية المدى، وهي أول قيمة إذا لم يكن المدى فارغاً. غيّر start في لعبة المدى.

قيمة النهاية (End value / stop)

حد النهاية غير المشمول. غيّر stop في لعبة المدى.

مقدار الزيادة أو الخطوة (Increment / step)

مقدار التغير بعد كل دورة. السالب للعد التنازلي و0 غير مسموح. غيّر step في اللعبة.

Lesson introduction — Computer Configuration

A computer is not one big device — it is a complete system of components working together: units that think, units that store, and units that input and output information. Today we learn about the five major components of a computer, peripheral devices, and the interfaces that connect them all.

Think of it this way:

A computer is like a work team: someone thinks and decides (the processor), someone saves (memory), someone brings information (input), and someone takes it out (output).

### ⚠️ Common Mistakes

Confusing main memory with secondary memory — the first stores temporarily, the second for long-term storage.

Confusing the control unit with the arithmetic unit — the first executes instructions and issues commands, the second performs calculations.

The Computer Components

the hardware and the five components — book page 85

Hardware is the devices such as the main computer unit and peripheral devices. Peripheral devices are the devices used by connecting them to a computer — like the keyboard, mouse, display, and printer.

A computer is comprised of five major components: the control unit, the arithmetic unit, the memory unit, the input unit, and the output unit. The control unit and arithmetic unit together are called the CPU.

Remember:

main memory temporarily stores programs and data, and secondary memory is for long-term storage — like hard disk, SSD, and USB memory.

The Interface

the component that mediates the exchange of information — book page 86

An Interface is a component that mediates the exchange of information. It is used for connecting the main computer and peripheral devices.

It is the port through which external devices exchange data with the computer — with famous types like USB, HDMI, and Ethernet.

Think of it this way:

An interface is like a door connecting rooms — from the computer room to the other devices' rooms, and data passes through it.

HDMI

video and audio over a single cable — book page 86

HDMI is a communication standard that allows video, audio, and other data to be transmitted through a single cable.

Compatible with digital televisions and audio equipment.

Think of it this way:

a single cable connects the computer to the TV, and then picture and sound travel together without many cables.

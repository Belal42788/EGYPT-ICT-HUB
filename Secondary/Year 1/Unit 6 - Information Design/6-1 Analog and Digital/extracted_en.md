What will we learn today?

Lesson introduction — the difference between analog and digital and converting between them

Today we will learn the difference between two basic types of data: Analog, which is represented by continuous values like temperature and time, and Digital, which is represented by numbers by dividing the value into regular intervals. Then we will see how to convert between them — A/D and D/A — and finally we will learn the Binary system that the computer relies on to represent everything.

Think of it this way:

Analog is like a clock with hands that move continuously, and digital is like a digital clock that shows jumping numbers. All the data around us — sound, image, temperature — we convert it to digital so the computer can understand it.

### ⚠️ Common Mistakes

Mixing up Analog and Digital — the first is continuous values without division, the second is dividing into intervals and numeric representation.

Mixing up A/D and D/A — the first is from analog to digital, the second is the reverse.

Thinking digital represents continuous values — no, digital divides the value into intervals and represents it numerically.

Analog refers to quantities that can be measured continuously and with fine precision, such as mass, time, or temperature. Data represented in analog form is called analog data.

An important example from the book: a mercury thermometer — as the temperature rises, the mercury column extends continuously along the scale. The value takes any point on the scale without being divided into intervals.

Remember:

Analog = continuous = takes any value in the range — like the clock hand that keeps moving.

Digital refers to quantities that continuously change but are represented numerically by segmenting them at regular intervals. Data represented in digital form is called digital data.

Going back to the thermometer: digital takes readings at regular intervals (for example a number every minute), not a continuous mercury column. Each interval takes a fixed number — this is the essential difference from analog.

Remember:

Digital = division + numbers = fixed jumps — like the digital clock that shows numbers.

A/D conversion, also called digitization, is the process of converting analog data into digital data. That means we take the continuous value, divide it into regular intervals, and convert it into numbers the computer understands.

Example: when you listen to sound on a computer, the sound wave (analog) is divided into intervals and each interval takes a number — the result is digital sound. We apply the same idea to images, temperature, and any continuous signal.

Remember:

A/D = Analog to Digital = we convert the continuous to numeric.

The binary system is a method of representing numbers using only two types of digits: 0 and 1. In computers, all types of information — numbers, characters, audio, images — are represented in binary.

Examples: the number 0 in binary is 0, the number 1 is 1, the number 2 is 10, the number 3 is 11, and so on. Each digit is called a bit, and groups of bits form any value in the computer.

Remember:

In the computer everything — numbers, characters, audio, images — is represented in the binary system 0 and 1.

converting digital data into analog data — from numbers to continuous values.

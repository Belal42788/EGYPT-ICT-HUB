HTML, CSS
13-2
HTML (HyperText Markup Language) is a language used to display web pages in a web browser. Its role is 
to create the structure of the page, such as headings, tables, and bullet points.
CSS (Cascading Style Sheets) is a language used to define the design of a web page. It allows for detailed 
specification of various designs, such as text size, fonts, and background colors.
By combining HTML and CSS, you can create web pages efficiently.

Warm Up
Let’s write a simple self-introduction page in HTML.
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>About Me</title>
</head>
<body>
  <h1>Ichiro</h1>
</body>
</html>
Copy and paste (or type) the code above into WebDen and run it.
A simple page is displayed.
Next, let’s change the text color and size using CSS.
HTML Code
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>About Me</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 class="name">Ichiro</h1>
</body>
</html>

CSS Code
.name {
  color: blue;
}
Copy and paste (or type) into WebDen and run it. 
The text has turned blue.
In this code, a class named class=“name” is specified inside the HTML tag, and the design for that class is 
defined in the CSS.
By specifying classes in this way, you can individually change the design even for tags of the same type.
Try adding more items (content) to display.
Try changing the text size and font.

# Presenting Your Website

What are we learning today?

Today we present the website we created in previous lessons to our peers. We prepare a summary of the key points of our website and present it to the group.

### Preparing the presentation

We summarize the main points of the website without telling every detail.

### Reviewing HTML, CSS, and JS

We review the most important thing we learned in the three languages.

### Presenting to peers

We present our summary to the group members with confidence.

Common mistakes

Telling every detail of the website — the presentation relies on key points only.

Forgetting to connect each part to the lesson we learned (HTML, CSS, JS).

How do we prepare the presentation?

Before presenting, we prepare answers to four important questions about our website: what is its theme? What did we learn in HTML? In CSS? In JavaScript?

Choose the website theme (hobbies, soccer, ...).

Summarize the most important thing you learned in HTML.

Summarize the most important thing you learned in CSS.

Summarize the most important thing you learned in JavaScript.

Present the summary to your group members.

A summary, not an explanation

We pick the important points that give a clear picture of the website in a short time.

Presenting to the group

After preparing the summary, we present it to our group and hear their opinion.

Common mistakes

Starting the presentation without preparing the summary first.

Forgetting one of the four questions — the summary must cover them all.

What did we learn in HTML?

HTML builds the page structure. We learned that CSS and JavaScript can be loaded into HTML using the link and script tags.

HTML brings the design from CSS and the behavior from JavaScript through two tags inside it.

We also learned that assigning an id to a button tag lets JavaScript control it, for example when we click it.

Common mistakes

Forgetting CSS is loaded via link, not just written alone inside HTML.

Forgetting the tag that must have an id is button so JavaScript can control it.

Q: CSS is loaded into HTML through which tag?
Options:
A. The script tag
B. There is no tag
C. The link tag
Correct Answer: C
Explanation: Correct! The link tag brings a CSS file.

Q: We add an id to which tag so JavaScript can control it?
Options:
A. The button tag
B. The img tag
C. The body tag
Correct Answer: A
Explanation: Correct! A button with an id can be controlled from JavaScript.

What did we learn in CSS?

CSS styles the page appearance. We learned to set the background color using the body selector, and control button colors with the button selector.

The body selector sets the background, and the button selector adjusts button colors and animations.

Common mistakes

Putting the background color in the wrong selector other than body.

Forgetting the button selector adjusts buttons too, not just texts.

Q: The background color is set with which selector?
Options:
A. The button selector
B. There is no selector
C. The body selector
Correct Answer: C
Explanation: Correct! The body selector sets the whole page background.

Q: Button colors and animations are adjusted with what?
Options:
A. The button selector
B. Buttons can't be styled
C. The body selector
Correct Answer: A
Explanation: Correct! The button selector adjusts buttons.

What did we learn in JavaScript?

JavaScript adds interactivity to the page. We learned that document.getElementById selects specific elements inside HTML, and addEventListener defines actions executed when a button is clicked.

The click is detected by addEventListener, the element is picked with getElementById, then the action runs.

Common mistakes

Using getElementById without adding the id in the HTML.

Forgetting addEventListener needs the event type (like click) and the action function.

Q: We select an element from HTML with what?
Options:
A. document.createElement
B. document.getElementById
C. document.location
Correct Answer: B
Explanation: Correct! document.getElementById selects the element by its id.

Q: Click actions on a button are defined with what?
Options:
A. addEventListener
B. CSS selector
C. By itself, no code
Correct Answer: A
Explanation: Correct! addEventListener defines an action that runs on click.

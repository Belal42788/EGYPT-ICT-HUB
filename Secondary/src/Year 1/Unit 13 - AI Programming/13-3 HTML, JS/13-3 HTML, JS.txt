Warm Up
Let’s try modifying the self-introduction page using JavaScript.
HTML Code
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>About Me</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <h1 id="name">Ichiro</h1>
</body>
</html>
JavaScript Code
document.getElementById("name").textContent = "Ohtani";
Copy and paste (or type) into WebDen and run it.
The name has changed.


=== PAGE 182 ===

183
Next, let’s try changing the text using a button operation.
HTML Code
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>About Me</title>
</head>
<body>
  <p id="name">Ichiro</p>
  <button id="btn">Change Text</button>
</body>
</html>
JavaScript Code
const p = document.getElementById("name");
const btn = document.getElementById("btn");
btn.onclick = () => {
  p.textContent = "Ohtani";
};
Copy and paste (or type) into WebDen and run it.
When you press the button:
The name changed.


=== PAGE 183 ===

184
Let’s try changing the text size.
HTML Code
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>About Me</title>
</head>
<body>
  <p id="name">Ichiro</p>
  <button id="btn">Change Size</button>
</body>
</html>
JavaScript Code
const text = document.getElementById("name");
const btn = document.getElementById("btn");
btn.onclick = () => {
  text.style.fontSize = 50 + "px";
};
Copy and paste (or type) into WebDen and run it.
When you press the button:
The name’s text became larger.

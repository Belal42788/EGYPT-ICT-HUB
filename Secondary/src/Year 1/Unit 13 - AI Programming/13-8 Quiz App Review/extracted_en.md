What did we learn in HTML?

In HTML we learned we specify the app title using the title tag, and assigning a class to an element lets CSS control it easily.

The title is written in the title tag, and the class gives CSS an anchor point for the element.

Common mistakes

Forgetting the title belongs in the title tag, not in the page body.

Mixing up class and id — class targets multiple elements, id targets one.

Q: The app title is set with which tag?
Options:
A. The body tag
B. The button tag
C. The title tag
Correct Answer: C
Explanation: Correct! The title tag sets the title.

Q: Assigning a class to an element gives CSS what?
Options:
A. An anchor to control it
B. A navigation link
C. It's useless
Correct Answer: A
Explanation: Correct! The class gives CSS a control point on the element.

What did we learn in CSS?

In CSS we learned we set the background color and font with the body selector, and set choice buttons' size and color with the .choice class selector.

body sets the page background and font, and .choice styles the choice buttons.

Common mistakes

Forgetting the class selector starts with a dot (.) in CSS.

Putting the background color in .choice instead of body.

Q: Background color and font are set with which selector?
Options:
A. The .choice selector
B. The body selector
C. There is no selector
Correct Answer: B
Explanation: Correct! The body selector styles the whole page.

Q: Choice buttons' size and color are set with what?
Options:
A. The body selector
B. Buttons can't be styled
C. The .choice selector
Correct Answer: C
Explanation: Correct! With the .choice class selector.

What did we learn in JavaScript?

In JavaScript we learned multiple options are handled with an array named choices, and the text color for correct or incorrect answers changes using an if...else statement.

The options are stored in an array, and if...else decides if the answer is correct and changes the text color.

Common mistakes

Forgetting the options are stored in an array and writing them separately.

Forgetting if...else needs a comparison condition to check the answer.

Q: Multiple options are handled with what?
Options:
A. an array named choices
B. animated images
C. CSS alone
Correct Answer: A
Explanation: Correct! With an array named choices.

Q: The text color for correct and incorrect answers changes with what?
Options:
A. a CSS selector
B. if...else
C. The color is fixed
Correct Answer: B
Explanation: Correct! Using an if...else statement.

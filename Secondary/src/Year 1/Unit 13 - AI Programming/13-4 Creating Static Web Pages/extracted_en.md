# Creating Static Web Pages

What are we learning today?

Today we learn to use generative AI to create static web pages with HTML and CSS, and how to request, run, and modify the code.

### AI writes programs

Programming is one of AI's strengths — we request code with a plain sentence.

### Request, run, and modify

We write a Prompt, run the output in WebDen, then modify it ourselves.

### Code with errors

AI code may contain errors or be beyond our level — we must review it.

Common mistakes

Trusting the code without reviewing it — we must read and understand it.

Leaving code you don't understand — ask the AI to explain it first.

AI writes programs

Programming is one of the strengths of generative AI. We can write programs by giving instructions to the AI. But just like text generation, AI code may contain errors, and it may generate code beyond your current knowledge that is hard to understand.

We write a Prompt and the AI generates the code, then we review, run, and modify it.

Strength

We can create a whole page with one sentence like: create a self-introduction page using HTML and CSS.

Cautions

AI code may contain errors, and may include things hard for us. We must understand the code before using it.

Common mistakes

Assuming AI code is 100% correct — always review it.

Using complex code you don't understand — understand it first.

Steps to generate a page

To create a page with AI, we follow steps: open Copilot, write a Prompt, run the code in WebDen, modify it, and understand it. Finally, we organize the conversation with a clear name.

Open copilot.microsoft.com, sign in, and launch Copilot.

We write a Prompt like: create a self-introduction page using HTML and CSS.

We copy the code, paste it into WebDen, and run it.

We modify the code to make it our own page, and ask to explain it with the Prompt: Explain this code.

We organize the conversation by renaming it like: 04 Creating Static Web Pages.

Forgetting to organize the conversation by renaming for the next lesson.

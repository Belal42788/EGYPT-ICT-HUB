Lesson introduction — data organization and central tendency

The first step in data analysis is organizing it — we put it in a frequency distribution table or a histogram, then we use the measures of central tendency to summarize it: mean, median, and mode.

Think of it this way:

The mean is the average, the median is the middle value after sorting, and the mode is the most frequent value.

### ⚠️ Common Mistakes

Confusing the mean with the median — the mean is the sum of the data divided by the count, while the median is the middle value after sorting the data ascending.

Forgetting that if the number of data points is even, the median is the mean of the two central values.

Confusing the parts of a frequency distribution table — the class is the interval, the class width is its length, the class mark is its midpoint, and the frequency is the number of values in it.

Data Organization

the frequency distribution table and the histogram — book page 127

A frequency distribution table is a table that organizes and summarizes data — like Tokyo temperatures, for example.

One interval in the table is called a class, its length is the class width, its midpoint is the class mark, and the number of values in it is the frequency.

Think of it this way:

A histogram is the same table but as bars — each bar represents a class and its height represents the frequency.

### Example: February temperature distribution

The class '13 or higher and lower than 16' — the class width is 3 degrees, the class mark is 14.5, and the frequency is 3 days.

The frequency distribution table:

13–16 (3 days) · 16–19 (6 days) · 19–22 (15 days) · 22–25 (5 days) · 25–28 (1 day).

The histogram:

we draw bars above each class, and the bar height equals the frequency.

The Mean

the sum of the data divided by the count — book page 127

A measure of central tendency is a single numerical value representing the characteristic of a dataset.

The mean is the value obtained by dividing the sum of the data by the number of data points — and in spreadsheet software it is determined using the AVERAGE function.

Think of it this way:

Scores 6, 9, 3, 6, 10, 12, 4, 3, 8, 10, 7, 6 — their sum is 84 and the count is 12, so the mean is 84 ÷ 12 = 7.

The Median

the middle value — book page 127

The median is the value that appears at the center when all the data is arranged in ascending order.

If the number of data points is even, the median is the mean of the two central values — and in spreadsheet software it is determined using the MEDIAN function.

Think of it this way:

Data 3, 3, 4, 6, 6, 6, 7, 8, 9, 10, 10, 12 — the count is even, so the median = (6 + 7) ÷ 2 = 6.5.

The Mode

the most frequent value — book page 127

The mode is the value that appears most frequently.

When arranging data in a frequency distribution table, the class mark of the class with the highest frequency is considered the mode — and in spreadsheet software it is determined using the MODE function.

Think of it this way:

In the data 6, 9, 3, 6, 10, 12, 4, 3, 8, 10, 7, 6 — the number 6 appears 3 times, so it is the mode.

# آلية صفحات الويب والإيميلات - Mechanism of Web Pages and Emails

What will we learn today?

Lesson introduction — Mechanism of Web Pages and Emails

When you type a website address and press Enter, how does the page appear in front of you? And when you send an email, how does it reach the right person? Today we learn WWW, HTML, and URL, the steps of browsing a web page, the structure of an email address, and the sending and receiving protocols SMTP, POP, and IMAP.

Think of it this way:

A URL is like a house address with street and city, DNS is like a directory that gets you there, and an email is like a paper letter with a sender and recipient address.

### ⚠️ Common Mistakes

Confusing the URL with the Domain name — the URL represents the full page location and communication method, and the Domain name is a part of the URL.

Confusing the email protocols — SMTP is for sending, POP downloads and deletes from the server, and IMAP accesses emails stored on the server.

The URL and Its Structure

the page location and communication method — book page 105

A URL represents the location of a web page and the method of communication — like https://www.mext.go.jp/index.html.

A URL structure includes: the Scheme name (protocol like https), the Host name (server name), the name of organization, the type of organization, the country name, and the File name.

Think of it this way:

A URL is like a detailed address: the delivery method (https), the building (www), the company (mext), its type (go government), the country (jp Japan), and the requested page (index.html).

Process of Browsing Web Pages

from the DNS query to displaying the page — book page 105

The steps of displaying a web page: (1) query the DNS server for the IP address corresponding to the domain name, (2) the DNS server returns the IP address, (3) access via the IP address, (4) the web server displays the page.

Think of it this way:

Like asking for a house owner's address from a directory, then going there yourself — DNS is the directory and IP is the address.

Email Mechanism and Address Structure

a system for exchanging messages — book page 105

Email is a system for exchanging messages and data with specific users via the Internet — when sending an email, you use an email address.

An email address structure: Username (representing the user who identifies the recipient) + @ + Domain name (identifying the mail server the recipient uses) — like hanako@example.co.jp.

Think of it this way:

The Username is like the owner's name, @ is like the word 'at', and the Domain name is like the city and building name where they are.

Sending and Receiving Protocols

SMTP, POP, and IMAP — book page 106

SMTP is a protocol for sending emails to a mail server.

POP is a protocol used to download emails from the server and delete them from the server — while IMAP is a protocol for accessing emails stored on a mail server.

Think of it this way:

SMTP is like the postman who takes your letter, POP is like taking the letter from the mailbox and leaving it empty, and IMAP is like reading the letter and leaving it in place.

the email journey from sending to receiving

the SMTP — sending emails

the POP — download and delete from the server

the IMAP — accessing stored emails

## Contradictions and visual source checks



- Supplied Prep 1 English cover says 2025–2026; Arabic says 2026–2027. Each covered lesson was compared directly.

- Windows 7/ZIP install, Gmail example and colour-comparison diagrams were inspected as images. They illustrate the book, not an audit of today’s interfaces.

- The English retry example on physical PDF page 57 visually omits try. The Arabic counterpart supplies the intended structure; corrected examples follow Python documentation.

- Prep 3 physical PDF page 64 is a Unit 2 cover, not input-error lesson content. Both ranges now end at 63.

- The book’s Arabic Overfitting label is retained. Absolute claims about all AI needing big data, automatic improvement or guaranteed accuracy are qualified.

- Print-only function assignment is syntactically valid and stores None. It is not labelled an invalid statement merely because return is absent.

- Tiny-model fits are independently calculated from four synthetic training points. Test references are held out. Raw linear test MAE is 1.15; raw interpolating-cubic test MAE is 7.00; the corrected synthetic sample yields zero for both. These are example-specific numerical results, not product-performance claims.
